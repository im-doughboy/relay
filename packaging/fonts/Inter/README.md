# Inter

Relay's interface font on every platform: Inter 4.1 by Rasmus Andersson
(https://rsms.me/inter/, https://github.com/rsms/inter), under the SIL Open
Font License 1.1 (OFL.txt). Only the Regular, Medium, SemiBold and Bold static
fonts are included; Qt falls back to the system's fonts for scripts Inter
doesn't cover.
